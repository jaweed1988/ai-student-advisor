# 🎓 Student AI Advisor

**GPT-4o powered academic risk advisor for higher education.**

> Project 3 of 100 · AI Engineering Portfolio · Learn by Doing

---

## What it does

Generates synthetic student records, feeds each student's academic profile
directly to GPT-4o, and returns a structured risk assessment with specific
advisor interventions. No rules. No ML model. GPT-4o reasons over the data.

---

## Architecture

```
data_generator.py    →    advisor.py    →    api.py + dashboard.py
  (synthetic data)     (GPT-4o analysis)     (FastAPI + Streamlit)
```

## Setup

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Add your OpenAI API key
cp .env.example .env
# Edit .env and add: OPENAI_API_KEY=sk-...

# 3. Generate student data
python -m student_advisor.data_generator

# 4. Run tests
pytest

# 5. Start API
uvicorn student_advisor.api:app --reload

# 6. Launch dashboard
streamlit run src/student_advisor/dashboard.py
```
